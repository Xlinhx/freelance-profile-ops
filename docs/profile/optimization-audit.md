## Mục Tiêu Kinh Doanh

Tối ưu profile để phục vụ kiếm khách hàng freelance:

- Upwork: nhận job trực tiếp từ client quốc tế.
- LinkedIn: xây trust, outbound/inbound, case study chuyên nghiệp.
- YouTube: show tính năng sản phẩm và proof dài cho khách xem trước khi nhắn.
- TikTok: giữ persona `Chủ Nô AI`, kéo reach, đưa người xem sang proof/contact.
- Facebook: local trust và network quen.
- Zalo: contact trực tiếp cho khách Việt.
- CV portfolio: landing proof gọn, đáng tin, gom link social và CTA.

## Kiến Trúc Funnel Đề Xuất

Client quốc tế:

```text
Upwork profile/proposal -> Upwork message -> Upwork contract
LinkedIn profile/post -> LinkedIn DM -> Upwork/email/call tùy case
```

Client Việt Nam:

```text
TikTok/YouTube/Facebook -> CV portfolio -> Zalo/Facebook/LinkedIn
YouTube demo -> Zalo 0932433459 hoặc email
```

Proof backbone hiện tại:

```text
CV portfolio + YouTube demo public/unlisted có chủ đích + screenshot/case study đã che dữ liệu
```

GitHub chỉ là proof kỹ thuật đọc thêm, chưa chỉnh.

## Avatar

Chuẩn đề xuất:
