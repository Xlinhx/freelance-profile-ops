# CV Update Rules

## Mục Tiêu

CV/portfolio public là nơi gom năng lực, proof và CTA liên quan trực tiếp tới việc chốt khách.

Nó không phải link hub cho mọi nền tảng.

## Được Phép Đưa Vào CV

- project đủ proof
- case study
- demo link
- GitHub khi thật sự hỗ trợ proof kỹ thuật
- video walkthrough hoặc YouTube link khi trực tiếp giải thích project
- contact liên quan trực tiếp như email hoặc Zalo nếu cần

## Không Đưa Vào CV

- Upwork
- TikTok
- Facebook
- các nền tảng social không trực tiếp tăng chất lượng proof của project
- các link chỉ để "cho đủ hệ sinh thái"

## Quy Tắc Chọn Project Lên CV

- phải có proof đủ rõ
- nên có outcome hoặc pain point rõ
- không tự thêm project thiếu screenshot, thiếu case note hoặc thiếu ngữ cảnh

## Quy Tắc Cho Agent

- không tự đưa Upwork vào CV/portfolio
- không tự nhét social links không liên quan vào footer hoặc section contact
- nếu cần thêm một link vào CV, phải giải thích được link đó hỗ trợ proof gì
