# VanHien Rebuild Plan

## Mục tiêu

Đưa VanHien từ mức `tạm được` lên mức `rất tốt`, làm baseline sạch trước khi sang EngPath.

## Phase 1. Asset Surgery

Recapture có chọn lọc:

- chat:
  - full shot sạch
  - question state
  - response state
  - controls state nếu thật sự cần
- multiverse:
  - full shot sạch
  - root state
  - branch state
  - storyline list state
- teacher suite:
  - dashboard overview
  - classes
  - bank
  - library nếu còn đủ giá trị
- create / handoff:
  - state click / state sau giao bài rõ hơn nếu bản hiện tại chưa đủ

## Phase 3. Visual Direction Mới

### Hook

- breadth signal bằng `system map` hoặc `breadth montage`
- không dùng 2 feature card ngang sức
- homepage chỉ là context, không phải nơi phải đọc sâu

### Chat

- 1 proof card chính: answer
- 1 proof card phụ: question hoặc input
- bỏ line nếu không tăng độ rõ

### Multiverse

- 1 root
- 1 branch proof
- 1 storyline list
- thứ tự đọc rõ: root -> branch -> broader system

### Results

- 1 proof chính
- 1 proof phụ
- proof phụ còn lại chỉ dùng nếu rất rõ
